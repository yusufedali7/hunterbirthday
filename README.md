# Kıvılcım'ın Doğum Günü Macerası

Kıvılcım için hazırlanmış, Hunter macerası esintili kişisel doğum günü sitesi.

Siteyi açmak için `index.html` dosyasını bir tarayıcıda açmak yeterli. GitHub Pages'a yüklenmeye hazırdır; `.nojekyll` dosyası özellikle bu amaçla eklenmiştir.

## GitHub Pages'ta yayınlama

1. ZIP dosyasını bilgisayarında aç.
2. İçindeki tüm dosya ve klasörleri GitHub deposunun ana dizinine yükle.
3. GitHub'da **Settings → Pages** bölümüne gir.
4. Kaynak olarak ana dalı ve `/ (root)` klasörünü seçip kaydet.

Site birkaç dakika içinde verilen GitHub Pages bağlantısında açılır.

## Müzik

Site müziği `assets/music/world-of-adventurers.mp3` dosyasındadır. Tarayıcı kuralları nedeniyle müzik otomatik başlamaz; ziyaretçi ekrandaki oynatma düğmesine dokunur.

## Gizlilik notu

Bu proje kişisel fotoğraflar içeriyor. GitHub Pages üzerinde yayınlandığında bağlantıyı bilmeyen kişiler de teknik olarak fotoğraflara erişebilir. Yayınlamadan önce Kıvılcım'ın fotoğraflarının internette yer almasına uygun olduğundan emin olun.

Eklenen şarkı telifli olabilir. Herkese açık GitHub Pages yayınında kullanmadan önce gerekli kullanım hakkına sahip olduğunuzdan emin olun.

## İçerik düzenleme

Duygusal mektup ve görev metinleri `index.html` içinde bulunur. Fotoğraflar `assets/photos` klasöründedir.
